# 공지 초안 (프로젝트 커뮤니티 · 공지 타입으로 등록)

> **중요:** 1DD 커뮤니티 게시글은 **Markdown을 렌더링하지 않습니다.** `**굵게**`, `` `코드` ``, `### 제목` 등은 **그대로 문자로 보이므로**, 아래 **「평문 본문」**처럼 **순수 평문**으로 작성하세요.

아래 내용을 프로젝트 **커뮤니티 → 공지 작성**에 붙여 넣거나, API로 등록할 때도 동일한 평문을 사용하세요.

---

## 제목 (평문)

프로젝트 설정에 LLM·API 연동을 열었습니다 (공개 문서 · 토큰 · 공개 API)

## 평문 본문 (커뮤니티·API 공통)

2. 공개 LLM 연동 문서 (…/llm-manual)

## 이미 등록한 공지를 평문으로 바꾸기 (API)

`announcement.write` 스코프가 있는 토큰으로 `v1_llm_public_announcement_update`를 호출해 본문만 교체할 수 있습니다.

저장소에 예시 스크립트가 있습니다.

- 파일: `docs/todo/apply-plain-announcement-update.py`
- 대상 포스트 ID: `4d5f4634-c346-4247-9152-e1ad21452a3c`
- 실행 예:

```bash
LLM_PAT='odd_pat_발급_직후_복사한_평문' python3 docs/todo/apply-plain-announcement-update.py
```

## API로 공지 등록 가능 여부 (결론)

가능합니다. 로그인 세션 없이 anon 키 + 프로젝트 액세스 토큰(`odd_pat_…`)으로 `odd.v1_llm_public_announcement_create` RPC를 호출할 수 있습니다. 토큰에 `announcement.write` 스코프가 있어야 합니다.

**단, UI가 Markdown을 지원하지 않으면 본문은 위 「평문 본문」과 같이 작성하세요.**

| 구분 | 설명 |
|------|------|
| UI 공지 작성 | `v1_create_community_post` 등 — 로그인(`authenticated`) + 소유자 검증. |
| PAT 공개 API | `067`~`069` SQL — `v1_llm_public_announcement_list` / `_create` / `_update` / `_delete` 등. `fn_llm_validate_public_access` 로 토큰·스코프 검증. |

보안: 채팅·문서에 액세스 토큰 평문을 붙이지 마세요. 이미 노출된 토큰은 설정에서 폐기 후 재발급하는 것을 권장합니다.
